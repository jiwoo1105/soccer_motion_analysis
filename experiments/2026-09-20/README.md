## 어깨·골반 결과 해석

- 3점 영상의 M은 0.04548–0.04759, 기준은 0.08065–0.08514였습니다. 기존 큰 회전 폭이 겹치던 문제에 대해 다른 측정 대상을 시험한 결과입니다.
- 등급 영상 9편의 순위 상관은 SG5/9/13에서 0.924/0.890/0.865였습니다. 높은 상관을 보인 설정 하나만 고르지 않고 가운데 창인 SG9를 대표로 표시했습니다.
- 5점 영상은 3점 영상과 거의 겹치며 7-2가 두 8점 영상보다 큽니다. 앞뒤 절반의 순위도 안정적이지 않았습니다. [세부 집계](body_validation.json)
- 기준 대비 점수는 움직임 크기의 환산값입니다. 기준과 같은 숙련도를 예측했다는 뜻이 아니며, 과도한 흔들림에도 높은 값이 나올 수 있는지는 추가 검증이 필요합니다.

## 공/헤드업과 재현 조건

유지된 영상의 원본 2,853프레임에 발목 주변 ROI를 적용했습니다. 45개 방향 전환 이벤트가 헤드업 조건을 통과했습니다. 실제 접촉 프레임의 정답 라벨이 아니며, 중심을 ±2프레임 이동하면 영상별 평균 헤드업 변화량은 최대 약 2.47° 달라졌습니다.

기존 측정에 사용한 검출 환경은 Python 3.11.12, Ultralytics 8.4.22, Torch 2.10.0, OpenCV 4.10.0, MPS/batch8입니다. 이번 공개 코드의 한 영상 추론 확인은 같은 OpenCV 4.10.0에서 MPS/batch16으로 실행했고 후보 좌표·신뢰도가 같았습니다. 패키지/장치 차이로 모든 환경에서 비트 단위 일치를 보장하지는 않습니다.

`evaluate.py`로 11편의 헤드업·상체·어깨골반 측정값과 점수·총점을 독립 계산해 `results.json`과 절대 오차 1e−8 이내로 대조했습니다. 채택된 45개 원본 프레임 인덱스와 후보 개수도 일치했습니다. ROI 기하는 2,853프레임 모두 기존 실험과 같았고, 3-1의 240프레임 재검출(후보 298개) 및 MediaPipe 재추출도 기존 결과와 일치했습니다.

원본 영상과 프레임별 추적 캐시는 공개하지 않습니다. 공개 스냅샷은 회귀 검증의 비교 대상이며 계산 입력이 아닙니다. 새 영상에서는 해당 영상의 manifest, 추적 검수, 관절 추출 및 공 검출이 필요합니다.
