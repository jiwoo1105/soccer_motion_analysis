## 이전 ±30 실행에서 확인한 범위

직전 `2026-10-11-sam2-touch-window` 버전에서는 새 추론3편771프레임, 사람이 없는40프레임의 전 항목N/A, 공식 로컬 모델3개 해시, 별도clone의215개 테스트를 확인했습니다. 이는 당시 버전의 기록이며 이번 ±16 설정에서 새 추론이나 새clone 검사를 반복했다는 뜻이 아닙니다. 저장된 SAM211편의6개 창66개 속도가 원래 검출기와 일치했던 기록도 보존합니다.

## 환경과 검증 범위

Apple M4 Pro, macOS 26.5.2, Python 3.11.12에서 실행했습니다. YOLOv8과 SAM2는 MPS, MediaPipe Heavy는 설치된 로컬 런타임을 사용했습니다. 버전은 `requirements-runtime.txt`, `requirements-sam2.txt`와 예시 JSON에 기록합니다. 모델은 기존 공식 가중치를 사용했으며 이번 실행에서 새로 다운로드하지 않았습니다.

이 Mac에서는 `pip check`가 MediaPipe 0.10.21 휠의 플랫폼 메타데이터 경고를 표시합니다. import와 실제 3편 추론은 성공했으나 경고가 없는 환경이라고 기록하지 않습니다. SAM2의 선택적 CUDA 확장을 사용하지 않아 일부 마스크 후처리를 생략한다는 경고도 발생했습니다. CUDA 결과와 수치가 같다는 보장은 없습니다.

Linux GitHub Actions는 모델 없는 테스트를 실행합니다. Windows/Linux의 실제 모델 추론과 장치 간 수치 일치는 검증하지 않았습니다. 자동 터치 후보를 독립 전문가 GT로 판정한 기록도 아닙니다.

[과거 ROI 버전 검증 기록](https://github.com/jiwoo1105/soccer_motion_analysis/blob/d6b06c1/docs/validation.md)은 현재 SAM2 실행과 구분합니다.

## 이전 ±30 버전의 별도 GitHub clone 확인

GitHub의 `codex/touch-window-shoulder` 브랜치를 `--depth 1`로 새 폴더에 clone해 다시 확인했습니다. 기존에 검증한 Python 3.11 가상환경을 사용했으며, 새로운 빈 가상환경에 의존성을 모두 재설치한 검사는 아닙니다.

- 테스트 215개 통과.
- 공식 로컬 모델 3개 설치와 `setup_models.py --check` 성공.
- 실제 영상의 검증된 SAM2 캐시를 재사용했을 때 원시값 유지. 비중 30/60/10의 총점과 반올림 전 가중합 일치.
- 사람 없는 40프레임 입력을 기본 경로로 새 추론하여 모든 항목과 총점 N/A 확인.
