# 실행 검증 기록

검증일: 2026-10-11. 프로필: `2026-10-11-sam2-touch-window`.
실행과 계산의 재현성을 확인한 기록이며, 전문가 등급 예측 성능 검증은 아닙니다.

## 확인 결과

| 검사 | 결과 |
|---|---|
| 전체 자동 테스트 | `python -m pytest -q`: 215개 통과 |
| 독립 코드 검토 | 수치 계산과 CLI, 추적, 캐시, 모델 준비 범위에 수정 필요 사항 없음 |
| 기존 검출기와 일치 | 저장된 SAM2 영상 11편, 6개 창의 66개 속도 결과 일치 |
| 원본 영상 새 추론 | 3편, 총 771프레임에서 관절 추출부터 PNG/HTML/JSON 생성 완료 |
| 캐시 재계산 | 새 추론 3편의 원시값과 점수가 1e−10 이내 일치 |
| 측정 불가 입력 | 사람이 없는 40프레임 영상에서 세 항목과 총점 모두 N/A |
| 모델 준비 | 기존 로컬 모델을 복사한 뒤 공식 SHA-256 확인 및 `--check` 통과 |
| 논문 수정 범위 | 어깨 관련 본문과 명칭, 구조도만 수정. 공 추적, 터치, 상체, 헤드업 본문 및 참고문헌 보존 |

독립 검토에서는 무작위 신호 300개에 대해 원래 터치 검출기와 비교하고, 1,000개 창 조합에서 겹치는 프레임 쌍의 중복과 결측 연결이 없는지 확인했습니다. 자동 테스트는 모델 없는 환경에서도 실행할 수 있습니다.

## 실제 원본 영상 결과

캐시를 쓰지 않고 세 영상을 한 번의 CLI 실행에 입력했습니다. 기본 YOLOv8n+SAM2, 어깨 ±30, 헤드업 ±16, 비중 10/80/10을 사용했습니다. 영상 이름별 수동 제외나 점수 보정은 적용하지 않았습니다.

| 영상 | 프레임 | 헤드업 ° / 점수 | 상체 ° / 점수 | 어깨 °/s / 점수 | 총점 |
|---|---:|---:|---:|---:|---:|
| 인,인 기준1 | 239 | 14.995 / 9.57 | 143.594 / 9.98 | 95.550 / 10.00 | 9.94 |
| 인,인 7-2 | 292 | 14.552 / 8.96 | 149.765 / 8.29 | 82.669 / 8.70 | 8.40 |
| 인,인 3-1 | 240 | 11.037 / 4.12 | 151.401 / 7.84 | 89.600 / 9.42 | 7.63 |

[파노라마](images/panorama-example.png), [HTML](example-report.html), [반올림 전 JSON](example-report.json)을 제공합니다. 원본 영상과 전체 관절 캐시는 공개하지 않습니다. 같은 원본을 입력해도 모델, 장치, 추적 품질에 따라 과거 수동 검수 표와 달라질 수 있습니다.

3-1이 여전히 높은 것은 실행 오류를 고쳤다고 해결되는 문제가 아닙니다. 이 값은 전체 숙련도 정답이 아닌 상체 동작의 잠정 비교값입니다. 상체 비중이 80%이고, 어깨 속도도 전체 등급과 순서가 다른 예외가 남습니다. 등급을 맞추기 위해 이 예외를 삭제하거나 가중치를 재학습하지 않았습니다.

## 환경과 검증 범위

Apple M4 Pro, macOS 26.5.2, Python 3.11.12에서 실행했습니다. YOLOv8과 SAM2는 MPS, MediaPipe Heavy는 설치된 로컬 런타임을 사용했습니다. 버전은 `requirements-runtime.txt`, `requirements-sam2.txt`와 예시 JSON에 기록합니다. 모델은 기존 공식 가중치를 사용했으며 이번 실행에서 새로 다운로드하지 않았습니다.

이 Mac에서는 `pip check`가 MediaPipe 0.10.21 휠의 플랫폼 메타데이터 경고를 표시합니다. import와 실제 3편 추론은 성공했으나 경고가 없는 환경이라고 기록하지 않습니다. SAM2의 선택적 CUDA 확장을 사용하지 않아 일부 마스크 후처리를 생략한다는 경고도 발생했습니다. CUDA 결과와 수치가 같다는 보장은 없습니다.

Linux GitHub Actions는 모델 없는 테스트를 실행합니다. Windows/Linux의 실제 모델 추론과 장치 간 수치 일치는 검증하지 않았습니다. 자동 터치 후보를 독립 전문가 GT로 판정한 기록도 아닙니다.

[과거 ROI 버전 검증 기록](https://github.com/jiwoo1105/soccer_motion_analysis/blob/d6b06c1/docs/validation.md)은 현재 SAM2 실행과 구분합니다.

- 실제 영상의 검증된 SAM2 캐시를 재사용했을 때 원시값 유지. 비중 30/60/10의 총점과 반올림 전 가중합 일치.
- 사람 없는 40프레임 입력을 기본 경로로 새 추론하여 모든 항목과 총점 N/A 확인.
