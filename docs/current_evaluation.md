# 현재 세 지표 계산법 — 2026-09-20

현재 진입점은 [`evaluate.py`](../evaluate.py), 수치 구현은 [`scoring/current_metrics.py`](../scoring/current_metrics.py)입니다. 이 문서는 공개 코드의 계산과 기존 영상에서 확인한 범위를 설명합니다.

## 1. 기존 방식에서 바뀐 점

이전 어깨·골반 항목은 각 부위의 추정 3D 좌표를 XZ 평면에 투영해 `atan2(vz,vx)` 방향각을 구했습니다. 각도 연속화, 이상치 처리, 평활화 뒤 극대·극소의 차이를 평균했습니다. 실험 버전에 따라 느린 성분을 빼는 단계도 있었습니다. 이것은 **부위별 회전 폭**이므로 큰 값만으로 공 방향에 빠르게 반응했다고 해석할 수 없습니다.

3-1과 기준 영상의 큰 회전 폭이 겹치는 현상을 깊이 추정 오류 하나로 확정하지 않았습니다. 실제로 천천히 몸 방향을 바꾸는 동작, 추정 좌표의 불안정, 잘못된 사람을 추적하는 문제를 분리해 검토했습니다. 추적 대상이 잘못된 영상은 제외하고, 화면에서 어깨와 골반의 상대적인 움직임을 측정하는 지표를 비교했습니다.

| 구분 | 과거 회전 폭 | 현재 어깨·골반 항목 |
|---|---|---|
| 측정 대상 | 어깨와 골반 각각의 방향 변화 | 어깨선과 골반선의 상대 정렬 변화 |
| 좌표 | 추정 3D XZ | 이미지 2D 픽셀 XY |
| 요약 | 연속 극값 차 평균 | 평활화한 시계열 P95−P5 |
| 단위 | 도(°) | 무차원 |
| 공·터치 사용 | 회전 폭 자체에는 필요 없음 | 필요 없음 |

깊이값에 대한 직접 의존은 어깨·골반 항목에서 제거했습니다. 헤드업과 상체 각도는 여전히 추정 3D 좌표를 사용합니다.

## 2. 입력과 품질 기준

[`manifest.json`](../experiments/2026-09-20/manifest.json)에 13편의 원본 프레임 수·등급·기준 영상 여부·제외 사유를 기록했습니다. 6-1과 7-3은 다른 사람에게 스켈레톤이 붙는 사례가 확인되어 **영상 전체**를 제외했습니다. 남은 11편은 등급 영상 9편과 기준 2편입니다. 값이 등급에 맞지 않는다는 이유로 영상을 제외하지 않았습니다.

품질 검토는 3,425개 원본 프레임의 수치 검사와 서로 다른 303프레임의 원본/오버레이 확인으로 진행했습니다. 모든 프레임을 수동으로 정답 판독한 것은 아닙니다. 유지된 영상에도 관절 추정 오차가 남을 수 있습니다.

Pose NPZ 필드:

| 필드 | 형태/뜻 |
|---|---|
| `frame_numbers` | 추출 성공 프레임의 원본 0-based 인덱스, 고유·오름차순 |
| `timestamps` | 추출기가 기록한 시각 |
| `landmarks`, `world_landmarks` | `(N,33,3)` 이미지 정규화 좌표 / 추정 월드 좌표 |
| `visibility` | `(N,33)` 가시성 |
| `frame_width`, `frame_height` | 원본 영상 폭/높이 |

평가 시 원본 길이의 배열로 복원하고 빠진 프레임은 NaN으로 유지합니다. 성공 프레임만 이어 붙여 공과 관절의 시간이 어긋나지 않도록 했습니다. 후보 JSON의 포즈 SHA-256과 현재 NPZ 해시가 다르면 계산을 중단합니다.

현재 영상은 1920×1080, 약 29.97fps입니다. 고정 프레임·픽셀 기준은 이 조건에서 사용했습니다. 다른 FPS/해상도에서는 결과에 경고를 남기며, 동일한 검증이 끝난 것으로 간주하지 않습니다.

## 3. 어깨·골반 상대 정렬 변화량

왼쪽/오른쪽 어깨는 MediaPipe 11/12, 골반은 23/24입니다. 정규화된 이미지 XY에 영상 폭/높이를 곱해 픽셀 좌표 $u$로 바꿉니다.

$$\mathbf{s}_t=\mathbf{u}_{12,t}-\mathbf{u}_{11,t},\qquad \mathbf{p}_t=\mathbf{u}_{24,t}-\mathbf{u}_{23,t}$$

$$L_t=\left\|\frac{\mathbf{u}_{11,t}+\mathbf{u}_{12,t}}2-\frac{\mathbf{u}_{23,t}+\mathbf{u}_{24,t}}2\right\|$$

$$q_t=\frac{s_{x,t}p_{y,t}-s_{y,t}p_{x,t}}{L_t^2}$$

화면에서 두 선이 평행하면 $q=0$입니다. $q$는 두 선 사이의 각도뿐 아니라 투영된 두 선의 길이에도 영향을 받습니다. 따라서 단순한 두 선 사이 각도나 실제 3D 축회전으로 표현하지 않습니다.

네 관절의 visibility ≥0.5, 좌표 유한, 몸통 길이 >1px인 프레임을 사용합니다. 유효 구간이 13프레임 이상 연속될 때 SG(9,2)를 적용합니다. 결측 구간은 연결하지 않습니다. SG5·9·13 비교에 같은 프레임을 쓰기 위해 각 연속 구간의 앞뒤 6프레임을 공통으로 제외합니다.

$$\bar q_t=\operatorname{SavGol}(q_t,9,2),\qquad M=P_{95}(\bar q)-P_5(\bar q)$$

한두 번 튀는 최댓값·최솟값 대신 분포의 중앙 90% 폭을 요약합니다. 남은 샘플이 2개 미만이면 계산 불가로 처리합니다. 이는 변화 폭 계산의 최소 구조 조건이며, 충분한 관측 시간을 보장하는 검증 기준은 아닙니다. 지지 프레임 수와 전체 대비 비율을 함께 기록하며 50% 미만이면 점검 경고를 남깁니다.

공통적인 2D 평행이동·회전·등방 확대에는 수식상 불변입니다. 3D 카메라 시점, 신체 비율, 가림, 관절 오차에는 영향을 받습니다. 공 좌표·터치·깊이 z를 사용하지 않으며, 빠른 반응이나 협응의 정확성을 직접 측정하지 않습니다.

## 4. 공 후보와 헤드업

### 공 후보 생성

`redetect_balls.py`는 매 프레임 발목 27/28의 경계상자를 만들고, 어깨/골반 중점 간 픽셀 거리 $L$을 이용해 좌우로 $2\max(24,L)$, 위아래로 $\max(24,L)$만큼 확장합니다. 영상 바깥은 잘라냅니다. 고정된 화면 오른쪽 삭제가 아니라 발목을 따라 움직이는 영역입니다.

YOLO11s (`imgsz=640`, confidence 0.1, IoU 0.7, class 32, `rect=False`, `half=False`, batch 16)로 검출하고 모든 NMS 통과 후보를 원본 좌표로 되돌려 보존합니다. 가시성이 낮아도 원시 후보는 기록하며, 포즈가 없거나 영역이 잘못되면 전체 화면 검출로 대체하지 않습니다.

### 후보 선택과 방향 전환

후보 중 반지름/몸통길이 0.15–0.50, 상자 가로/세로 0.5–2.0, 발목 거리/몸통길이 ≤2.5를 만족하는 공에서 반지름이 가장 큰 것을 선택합니다. 이것만으로 해당 공의 신원이 보장되지는 않습니다.

- 최대 3프레임 결측만 보간합니다. 양 끝 이동속도는 ≤40px/frame이어야 합니다.
- 연속 관측 사이 >80px/frame 이동은 점프로 기록합니다.
- 공 X를 연속 구간에서 SG(11,2)로 평활화합니다. 극대·극소 후보에 prominence 10px, 간격 8프레임을 적용하고 합친 후보도 8프레임 이상 떨어지게 유지합니다.
- 후보 ±13프레임의 공 관측/보간 지지, ±8프레임 관측률 ≥80%, 중심의 실제 검출, 점프 부재, 가까운 발목 거리 ≤200px 및 visibility ≥0.5를 요구합니다.

**공 X 방향 전환은 터치 시점의 대리 후보입니다.** 실제 발–공 접촉의 수동 정답 라벨은 아닙니다. 이번 검토에서 222개 원본 프레임과 채택 중심을 확인했으나 접촉 타이밍 오차를 정답과 대조한 검증은 남아 있습니다.

### 헤드업 변화 폭

추정 월드 좌표에서 양 눈(2/5) 중점과 양 어깨(11/12) 중점을 잇는 벡터 $\mathbf h_t$를 구합니다. 수직 위쪽 $\mathbf e_y=(0,-1,0)$과의 각도입니다.

$$\phi_t=\arccos\frac{\mathbf h_t\cdot\mathbf e_y}{\|\mathbf h_t\|\|\mathbf e_y\|}$$

$$R_k=\max_{t\in[t_k-8,t_k+8]}\phi_t-\min_{t\in[t_k-8,t_k+8]}\phi_t,\qquad H=\frac1K\sum_{k=1}^K R_k$$

해당 17프레임에서 네 관절 visibility ≥0.5와 유효 머리 벡터를 요구합니다. 최소 2개 이벤트가 있어야 $H$를 계산합니다. 중심을 ±2프레임 옮기는 민감도는 모든 이동 창에서 머리 관측이 유효한 **동일 이벤트 집합**으로 계산하고 사용 개수도 저장합니다.

## 5. 상체 각도

기존 무릎–골반–어깨 각도를 유지합니다. 월드 좌표의 왼쪽 25–23–11, 오른쪽 26–24–12 세 점으로 각도를 구합니다. 여섯 관절의 visibility ≥0.5, 유한 좌표, 영벡터 아님을 만족하는 프레임에서 양쪽 평균을 구하고 전체 평균 $T$로 요약합니다. 엄밀한 몸통의 수직축 대비 각도가 아니라 **무릎–골반–어깨 사이 각도**입니다.

## 6. 점수 환산과 총점

고정값은 [`calibration.json`](../experiments/2026-09-20/calibration.json)에 있습니다. 새 영상을 넣을 때 그 영상의 등급에 맞춰 다시 적합하지 않습니다.

$$S_H=\operatorname{clip}_{[0,10]}\left(10\left[1-\frac{|H-H_{ref}|}{\tau_H}\right]\right),\quad S_T=\operatorname{clip}_{[0,10]}\left(10\left[1-\frac{|T-T_{ref}|}{\tau_T}\right]\right)$$

$$S_B=10\min\left(1,\frac{M}{M_{ref}}\right),\qquad S_{total}=\frac{S_H+S_T+S_B}{3}$$

| 항목 | 기준값 | 폭/유래 |
|---|---:|---|
| 헤드업 | 12.364993° | τ=3.362722°; 재검출 후 기준 2편 평균, 유지 11편 표본표준편차×2 |
| 상체 | 143.537178° | τ=7.455044°; **과거 12편으로 만든 환산값 유지** |
| 어깨·골반 | M=0.0828979811 | 현재 기준 2편 M 평균 |

0점은 환산식 하한이고 움직임이 없다는 의미가 아닙니다. 기준 영상도 기준 두 편 평균과 차이가 있으므로 모든 항목이 10점일 필요는 없습니다. 하나라도 계산 불가면 총점은 N/A이며, 나머지 둘의 가중치를 자동 확대하지 않습니다.

기존 상체 50%·헤드업 30%·어깨골반 20%는 이 표본에서 최적화·검증된 비율이 아니었습니다. 같은 수정 입력으로 세 비율을 비교했을 때 등급 영상 9편의 총점 순위 상관은 기존 비중 0.670, 동일 비중 0.754, 어깨골반 50% 비중 0.754였습니다. 특정 비중을 최적값으로 주장할 근거가 부족해 **각 1/3을 단순한 잠정 규칙**으로 사용합니다.

## 7. 결과와 남은 검증

전체 표·가중치 비교는 [실험 결과](../experiments/2026-09-20/README.md), 어깨골반 민감도 집계는 [body_validation.json](../experiments/2026-09-20/body_validation.json)에 있습니다.

- 어깨골반 SG5/9/13의 등급 순위 상관은 0.924/0.890/0.865 (등급 영상 n=9)입니다. 평활화 선택을 바꿔도 양의 관계가 남았습니다.
- 투영된 어깨/골반 폭 분포를 맞춘 SG9 비교의 상관은 0.865입니다. 폭이라는 대리변수 하나를 맞춘 것이므로 카메라 시점을 통제했다는 뜻은 아닙니다.
- SG9에서 같은 영상의 앞/뒤 절반 지표 순위 상관은 −0.283, 앞/뒤 구간의 등급 상관은 0.661/0.398입니다. 전체 영상의 관계가 짧은 구간에서도 안정적이지는 않습니다.
- 앞선 탐색에서 여러 후보를 비교했습니다. 24개 특징×3개 창×2개 표현=144개 후보 중 최대 상관의 선택 효과를 고려한 5,000회 순열 진단 maxT p는 0.067이었습니다. 현재 지표의 높은 상관을 독립적인 예측 성능으로 해석하지 않습니다.
- 총점 비교의 한 영상 삭제 범위는 **민감도 검사**입니다. 재학습 후 검증 영상을 예측한 교차검증이 아닙니다.
- 등급은 전체 드리블에 대한 값입니다. 어깨·골반 항목만의 전문가 라벨과 새로운 참가자/촬영 조건에서의 검증이 필요합니다.

## 8. 재현 확인과 공개 범위

공개 코드는 무시된 `output/` 아래 임시 분석 모듈을 import하지 않습니다. 원본 인덱스의 포즈와 ROI 후보로 수치를 독립 계산한 뒤 저장된 결과를 회귀 검증 대상으로만 사용합니다. 결과 스냅샷을 계산 입력으로 사용하지 않습니다.

11편의 세 측정값·점수·총점을 절대 오차 1e−8로 대조했고, 45개 채택 이벤트의 원본 프레임 인덱스도 일치했습니다. ROI 2,853프레임의 기하와 한 영상의 YOLO 후보 및 포즈 재추출을 기존 실험과 대조했습니다. 사용 모델·포즈 해시, 버전, FPS, 검출 파라미터를 출력에 기록합니다.

모델 추론은 패키지 버전·장치에 따라 수치가 달라질 수 있습니다. 원본 영상, 프레임별 관절/공 데이터, 모델 가중치는 공개하지 않습니다. 공개 집계표는 검토할 수 있지만 원본부터 재현하려면 해당 입력과 모델을 별도로 준비해야 합니다.
